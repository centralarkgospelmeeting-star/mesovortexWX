# MesoVortexWX

## The Vision

MesoVortexWX is an open\-source professional weather workstation designed for radar analysis, severe weather monitoring, forecasting, storm tracking, and meteorological research.

The goal is not to build another weather website.

The goal is to build a professional meteorological workstation combining the best aspects of:

- WeatherWise Pro
- RadarScope
- RadarOmega
- GRLevelX

while introducing modern capabilities such as:

- Advanced radar analysis
- AI\-assisted weather interpretation
- Weather station integration
- Spotter and chaser tools
- Flexible workstation layouts
- Open data integrations

The project is actively evolving and should be viewed as a platform rather than a finished product.

---

## Current Development Status

MesoVortexWX is under active development.

Features may be:

- Complete
- In progress
- Experimental
- Under validation
- Temporarily unavailable

The source code should always be considered the definitive reference for implementation status.

Contributors should not assume that a feature is complete simply because it appears in the interface.



### Professional Workflow

MesoVortexWX is intended for:

- Weather enthusiasts
- Spotters
- Storm chasers
- Forecasters
- Meteorologists
- Emergency managers
- Researchers

Workflow, speed, and information density are more important than visual trends.

### WeatherWise\-Inspired Layout

The intended user experience is a professional weather workstation.

Success means a WeatherWise Pro user can sit down in front of MesoVortexWX and immediately understand how to use it.

MesoVortexWX uses its own branding, logo, identity, and feature set while pursuing workstation\-level usability.

## Project Rules

### Accuracy First

Scientific accuracy is more important than feature count.

A working radar product is more valuable than ten partially working radar products.

### Real Data Only

Do not create fake weather products.

Do not generate synthetic operational data.

Do not present estimates as official observations.


### No AI Slop

Avoid:

- Generic dashboards
- Oversized cards
- Excessive whitespace
- Trendy UI redesigns

Build weather software, not a weather marketing site.

### Preserve the Workstation

New features should integrate into the workstation.

Do not redesign the application every time a feature is added.
