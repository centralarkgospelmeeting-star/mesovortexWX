# MesoVortexWX

This project is a working weather radar app foundation built with Next.js, TypeScript, Tailwind CSS, and Leaflet.

## Features

- Radar-style dark design
- Interactive map viewer
- Product switching for reflectivity, velocity, and dual-pol
- METAR panel styles
- Mobile-friendly layout
- API route foundation for future radar data integration

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Next step

This is the starter version. The next evolution is adding live NOAA/NWS radar feeds and multi-site product loops.
